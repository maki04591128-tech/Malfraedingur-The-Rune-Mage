## 1. ビジョン / 最終目標

### 1.1 ワンライン
> 古ノルド語の文法を読み解くほど魔法が強くなる、タイムリミット制ローグライク。

### 1.2 コアコンセプト
**言語学 × 魔法 × 積み重ね。**
プレイヤーは語彙と文法を組み合わせて呪文を構築する。理解が深まるほど魔法を「思い通りに」操れるようになり、死んでも言語知識だけは失われない。最終的に、ゲーム外のプレイヤー自身が古ノルド語の基礎を獲得していることが本作のゴールである。

### 1.3 完成の定義（Definition of Done — プロジェクト全体）
本作は以下を全て満たした時点で「完成」とみなす。

1. プレイヤーが語彙ゼロから始め、文法を学びながら呪文を構築できる。
2. 文法的正しさが呪文挙動に明確に反映される（威力ボーナス / 暴発リスク）。
3. 「理解度＝制御精度」モデルが体感できる（強い未習語は使えるが暴れる）。
4. 死亡で肉体はリセットされるが言語知識は永続する。
5. タイムリミット下での「戦う／学ぶ」のリソース配分にジレンマが成立する。
6. 1ループ（7日間／`1.5`）が「もう1ループやりたい」と思える長さで完結し、複数ループでメタ成長を実感できる。**「7日が体感どれくらいか」は INC-3 のプロトタイプ実測で確定する**（先に固定値を決め打ちしない）。
7. ゲームを通じて実在の古ノルド語語彙を最低 100 語、**基礎文法（格一致）**を自然に習得できる。数詞/持続/条件節などのストレッチ文法は、コアが成立した上で追加できていれば加点とする（必須ではない）。

> v0.2 注: 本作の「コア」は **動詞＋目的語＋格一致** までで成立する。完成判定の必須条件はコアであり、ストレッチ文法は将来拡張。スコープ詳細は `03_呪文文法仕様書.md` を正とする。

### 1.4 ターゲット体験（プレイヤーが言語化する感想）
- 「最初は呪文が暴発して怖かったが、格変化を理解したら命中するようになった」
- 「死んだのに、覚えた単語で次の周が明らかに楽になっている」
- 「いつの間にか辞書を見ずに呪文を組めるようになっていた」

### 1.5 枠物語（フレームナラティブ）— 確定

> 物語はテーマとメカニクスを支える最小限に留める（`01` 6章 非目標：大規模分岐はしない）。以下は確定設定。

世界は **7日後に滅びる**（古ノルド神話的終末＝Fimbulvetr/Ragnarǫk のモチーフ）。滅びの源は死者の国へ通じる門 **「Helgrind」**。

師匠は弟子である主人公に2つを託して逝く：

1. **時を巻き戻す語彙** — 失われた古い詠唱 `öld renna aptr`（「時代よ、後ろに流れよ」）。これを発すると時間が滅びの7日前に巻き戻る。**死に戻り／周回の物語的理由付け**。
2. **時を記録するアーティファクト** — 巻き戻しの基点（7日前の状態）を刻むルーンの遺物。**セーブ／ロードの物語的理由付け**。

主人公は **7日間というループ**を繰り返し、ダンジョン Helgrind を攻略して滅びを止める。

**ループの核心（テーマの物語的実装）**：
- 巻き戻すと **世界と肉体は7日前に戻る**（HP・到達・所持品リセット）。
- しかし **主人公の精神＝言語知識は巻き戻らない**（タイムループ物の記憶保持）。ゆえに「知識こそが唯一ループを越えて積み上がる武器」。これは本作のコア原則「肉体は滅びるが知識は残る」を**物語として airtight に**する。
- アーティファクトが記録するのは「時間の基点」であって知識ではない。知識が残るのは*巻き戻しても主人公が覚えているから*。最終的な知識の器はプレイヤー自身の記憶（3.7 のメタ構造と一致）。

**勝利条件**：いずれかのループ内（7日以内）に Helgrind を踏破し、滅びの原因を断つ。ループ回数に上限は設けない（知識による成長が進行＝ローグライトとして成立。終末は回数制ではなく Helgrind 攻略で解決する）。

## 3. 主要システム仕様

### 3.1 呪文言語システム（コア）
- 呪文は古ノルド語の **語を並べて構築** する。詳細仕様は `03_呪文文法仕様書.md` を正とする。
- 構成要素：動詞（効果）／名詞（対象・属性）／数詞（量）／時間語（持続）／条件語 `ef`／接続 `ok`／否定 `eigi`。
- **入力UX（確定）**: 通常モードは**習得済み語タイルを選んで並べる**方式。対象語タイルには**格サブ選択**（主格/対格…）を持たせ、格一致がコア体験として成立するようにする（選択式でも格は誤り得る＝学べる）。**無辞書モード**のみ、語形（格変化を含む綴り）まで自分で打つ**フルタイプ入力**で最高難度（暗記の実証）。トークナイザはタイル列・生テキストの両方を同一トークン列へ正規化する（`03`/`04`）。
- 例：
  ```
  fimm stund ef sjálfr sárr lækna sjálfr
  （5秒間 / もし自らが負傷していたら / 自らを癒せ）
  ```
- 文法的正しさ（格一致・数一致・語順）が **威力倍率** と **暴発確率** に直結する。
- 戦闘の進行は **3.8 戦闘モデル** に従う（コマンド入力型ターン制）。
- 本システムが本作の技術的最大リスク。INC-1（旧M1）で単独の縦切りプロトタイプとして検証する。

### 3.2 制御精度モデル（テーマの心臓）
理解度（comprehension, 0–100）は **威力ではなく制御精度** を表す。

| 状態 | 体験 |
|------|------|
| 強力な語を習得直後（理解度低 ≤30） | 暴発率は高め（最大10%）。だが失敗の質は**不発など軽傷**＝安全に試せる |
| 中程度（31–60） | 暴発率は下がるが、失敗すると**対象ズレ・威力低減**＝実行に失敗する |
| 高い（61–99） | 暴発は稀。しかし失敗すると**手元で暴発＝自分にダメージ／効果反転**＝最も危険 |
| 完全習得（100） | **暴発しない**（確率0）。効果が決定的 |
| 安全な既習語で戦う | 弱いが確実。被害が読める |

→ **暴発は理解度が上がるほど「頻度は下がるが内容は悪化」する非対称設計**（初心者の失敗は痛くない／達人の失敗は痛いが滅多に起きない）。確率は理解度のみで決まり、基準10%・理解度+1ごと−0.1pt・100で0（`03` §5.2）。
→ 「強いが暴れる新語」と「弱いが安定の既習語」の戦略的選択が常時発生する。
→ 数値設計の方針：**威力 = 語の固有ティア**（理解度に依存しない）／**暴発確率 = 理解度のみ**／**命中ぶれ = 文法正しさ**。詳細式は `03` §5。

### 3.3 語彙・理解度システム
- 語彙は探索（碑文・敵ドロップ・学習スポット）で **発見** する。
- 発見直後は意味が伏せられた状態。文脈・辞書・使用を通じて理解度が上がる。
- 理解度の上昇手段：
  - **文法的に正しく構築した呪文での使用**（実戦学習・低効率・時間を別用途に使える）。誤った呪文では理解度は伸びず、代わりに是正フィードバックが出る（`03` §7、D6）
  - 学習スポットでの集中学習（高効率・時間を大きく消費）
  - 碑文の翻訳成功（中効率・パズル報酬）
- 理解度は `Lexicon`（永続セーブ）に保存。巻き戻し（死亡）してもリセットされない（仕様 1.3-4）。
- 各語は **カナ読み**を表示補助として提示、詳細ビューで **IPA** を任意表示（音声なし）。発音は学習補助のみで判定・威力に不関与（DP1/DP2）。無辞書モードではグロスもカナ読みも隠す（DP3、`3.7`）。正典トークンは古綴ラテン表記（`03` 表記ポリシー）。

#### 3.3.1 文法習熟の扱い（項目5・確定）
- **文法は数値ステータスを持たない**（D1）。語彙のような「文法力」値は無い。文法の良し悪しは*その呪文が正しいか*（`G`）として命中精度とフィードバックに作用するのみ（`03` §5.4/§7）。
- **判定の厳しさは常に一定**（D3）。格一致・語順はゲーム開始時から厳格に判定される（寛容な段階は無い）。
- 学習段階で変わるのは **(a) UI 補助の量（最大→なしへ逓減）** と **(b) 使用できる構文の解禁範囲**のみ（`03` §6）。
- 解禁は **物語進行が主・習熟実証が従**（D2）。解禁・補助段階は **巻き戻しで戻らず恒久**（D7、知識側。`05` `grammar_progress`）。
- 究極的には文法知識もプレイヤー自身の腕に置く（メタ原則）。無辞書モードは補助ゼロ＋使用可能範囲で最厳判定（`3.7`）。

### 3.4 ローグライク周回構造（＝7日間ループ）
- 1周 = **7日間のループ**（`1.5`）。舞台はダンジョン **Helgrind**（死者の国の門）。
- Helgrind は複数階層（深層へ降りるほど危険／滅びの核心に近づく）。階層は**マス目グリッド上に部屋＋通路を手続き生成**（v0.9）。詳細は `09 §2`。
- 各階にルーン碑文（翻訳すると報酬／罠回避／近道、かつ語彙の学習契機）。INC-4 で本格化。
- 深層にボス。Helgrind 踏破＝滅びの原因を断つ＝**ゲームクリア**（その周で勝利）。
- 周の終了トリガは3つ：①7日経過（時間切れ）②死亡 ③踏破（勝利）。①②は巻き戻し（`3.6`）、③はエンディング。
- **巻き戻しで階層は再生成**（新規 seed）。起点部屋（プレイヤー初期位置）の配置のみループ間で固定（精神的アンカー）。詳細は `09 §2.5`。

### 3.5 タイムリミット（共通リソース＝7日間の持ち時間）
- 1ループの持ち時間は **7日間**（`1.5`/`3.4`）。世界時間はこの7日の予算として進行する（旧表現「Fimbulvetr countdown」＝滅びまでの7日に相当）。抽象単位で 168 ユニット（INC-3 暫定、`09 §4.2`）。
- 消費要因：**移動 1 タイル = Δ_move（既定 0.5、`09 §4.2`）**／戦闘（1 詠唱 = 1 手番＋詠唱固有 Δ）／学習（特に集中学習が重い）。旋回（向き変更のみ）は Δ 0（戦闘中の自由旋回を許す、`09 §3.2`）。時間単位（日/時）の換算と「7日が体感どれくらいか」は **INC-3 の実測 calibration で確定**（`02`/`05`）。
- **MP は採用しない。連打抑制は「ターン経済＋世界時間」で行う（確定）**：1詠唱＝1プレイヤーターン消費＋世界時間 Δ。Δ は語数・語ティアで増える（長く複雑・強力な呪文ほど7日を食う）。旧プロジェクトの MP の役割を時間制に統合し、「強い呪文を雑に撃つほど滅びが早く来る」というテーマ直結の抑制が働く。詳細は **3.8** と `05` BalanceConfig。
- 7日を使い切ると強制的に巻き戻し（周失敗）。ただし **語彙理解度は残る**（`3.6`）ため失敗も前進になる設計。
- これにより「学べば強くなるが、学ぶ時間が滅びを早める」というコアジレンマが成立。v0.9 のマス目移動導入により「歩く Δ も滅びを早める」ため、**経路選択（部屋を全部覗くか・最短で階段へ向かうか）にもジレンマが発生**する。

### 3.6 死亡と永続（＝巻き戻しと記憶保持）
死亡・時間切れは「死」ではなく **`öld renna aptr` による時間の巻き戻し**として演出する（`1.5`）。アーティファクトが記録した7日前の基点へ戻る。

| 巻き戻る（7日前の状態へ） | 巻き戻らない（精神＝知識） |
|----------------|----------|
| HP・ステータス・装備 | 語彙の理解度（Lexicon） |
| Helgrind 到達階・所持アイテム | 解禁済み文法ヒント |
| ループ中の一時バフ | 実績・統計（メタ記録） |

- 演出テーマ：「世界と肉体は7日前へ。だが主人公の覚えた言葉は戻らない」。巻き戻し画面で **今ループで新たに理解度が上がった語** を提示し、喪失感より蓄積感を与える。
- **任意巻き戻し（設計フック・確定）**：プレイヤーは死を待たず `öld renna aptr` を自分で唱えてループを能動的にリスタートできる（失敗ループの損切り）。コストは「経過した時間を失う」ことそのもの＝戦略的判断になる。実装はストレッチでよいが仕様として確定。
- セーブ／ロード＝アーティファクトの記録（`04` §7 と一致）。詳細なセーブ運用は `04`。

### 3.7 メタ構造：プレイヤー自身の学習
- 究極の永続データはセーブファイルではなく **プレイヤーの記憶**。
- 任意の「碑文モード（無辞書）」を用意：辞書ヒントを封じ、**語形（格変化を含む綴り）まで自分でフルタイプ入力**する高難度モード。さらに**文法補助も全段階ゼロ＋使用可能範囲で最厳判定を強制**（`03` §6.1）。人間の暗記と文法の腕のみで挑戦でき、本作のメタ・テーマを仕組みとして実証する。

### 3.8 戦闘モデル（v0.9 シームレス型に書換）
- **コマンド入力型ターン制 ＋ マス目位置取り・距離・方向の併用（シームレス型）。**
  - v0.3 で「リアルタイム/グリッド戦術は不採用、コアはグリッド非依存」と確定していた方針を v0.9 で**シームレス型（探索マップ＝戦闘マップ）に転換**。
  - シーン切替型（FF 風：探索→戦闘画面に遷移）は不採用。混合型（探索抽象＋戦闘局所グリッド）も不採用。**探索マップそのものが戦闘マップ**で、敵が視界に入った瞬間から距離・射程・方向の判断が走る（伝統的ローグの体感）。
  - 詳細は新規 `09_マップ・移動仕様.md` を正典とする。
- **「戦闘モード」は UI 状態の前景/後景の入れ替えで表現**（`09 §6.1`）:
  - 視界内に敵が 1 体以上いる → 「警戒モード」。HUD に最隣接敵の HP バー・推定脅威度・詠唱対象指定 UI が前面に。
  - 視界内に敵が 0 体 → 「平時モード」。時間残量・現在地・既知マップを大きく表示。
  - どちらのモードでもターン管理は同一（プレイヤー行動 → 敵行動 → 次ターン）。
- **手番構造**: プレイヤーターンに「**移動 1 タイル**／**旋回**（向きだけ変更）／**呪文を 1 つ構築して詠唱**／**待機・学習**」のいずれか 1 つを選ぶ → 解決 → 敵ターン。「逃走コマンド」は無い（視界から敵を外す動きで代替、`09 §6.4`）。
- **連打抑制（MP の代替）**: 1 詠唱 = 1 プレイヤーターン + 世界時間 Δ。1 移動 = Δ_move（既定 0.5）。Δ は語数・語ティア・行動種別依存（`05` BalanceConfig、`09 §4.2`）。MP は持たない。
- **詠唱の対象指定（位置あり）**: 3 系統を併存（`09 §6.3`）:
  1. **タイル直接指定**（UI クリック）。scaffold=max でデフォルト。
  2. **方向語**（`fram`/`aptr`/`vinstri`/`hœgri`）でプレイヤーの向き基準。
  3. **距離語**（`nær`/`fjarri`）と **形状語**（`vítt`/`í gegnum`）で射程・形状。
  - 範囲語・方向語が無い場合の既定: 射程 1（隣接）、対象 = 最隣接敵自動（`09 §7.1/§7.2`）。
- **解決順**: 詠唱は `03` のパイプライン（Tokenizer→Parser→Validator→Evaluator→**位置解決**→Resolver）で処理し、`ResolvedEffect` を戦闘に適用。**位置解決ステージ**で対象タイル集合 T を計算し、視界外・壁・射程外で T が空なら「届かない」finding（`09 §7.4`）。暴発時も原因を `GrammarReport` で必ず提示。
- **コア原則「理解度＝制御精度」を壊さない**: 射程・方向の追加は学習対象を増やすが、`P_base = Σtier` と暴発確率モデル（`03 §5.2`）はそのまま。位置の有無は威力式に乗らない（`09 §1`）。
- **scaffold=max の射程プレビュー必須**: 認知負荷増（タイル選択 + 格選択 + 位置移動 + 射程判断 + 方向指定）を吸収するため、scaffold=max では対象タイルハイライト・方向矢印・AoE 範囲のライブプレビューを実装する（`09 §9`）。
- **スコープ**:
  - **INC-3**: シームレス戦闘の最小実装。詠唱の位置解決はタイル直接指定のみで、範囲語・方向語は **データには載せるが Validator では minor finding にとどめる**（コア違反扱いしない）。
  - **INC-3.5**: 範囲語・方向語をコア文法判定に統合（コア違反扱い、暴発確率合算式に乗る）。INC-1/2 の H 判定を新仕様で再評価（`06`/`08` 再確認章）。
  - 詳細は `09 §8` および `02 §3` を参照。

## 4. ゲーム外学習目標（教育設計）

本作はゲームであると同時に学習体験である。明示的な学習目標を設計目標として固定する。

| 段階 | プレイヤーが習得する内容 | 対応ゲーム要素 |
|------|--------------------------|----------------|
| 入門 | 基礎語彙 約20語（自己・敵・火・氷・癒・打 など） | 序盤フロア・チュートリアル碑文 |
| 初級 | 名詞の格（主格/対格/与格/属格）と動詞の目的語要求 | 暴発の原因＝格不一致を体感させる設計 |
| 中級 | 数詞と名詞の数一致、時間語による持続表現 | 範囲・持続呪文の解禁 |
| 上級 | 条件節 `ef`、否定 `eigi`、接続 `ok` による複文 | プログラミング的詠唱・ボス攻略 |

→ 学習設計は `03_呪文文法仕様書.md` の文法スコープと一対一対応させる。

## 6. スコープ管理 / 非目標（Non-Goals）

**本作で「やらないこと」を明示する（スコープクリープ防止）。**

- マルチプレイヤー：対象外。
- 音声／フルボイス：対象外（リリースでも実装しない）。発音は**カナ読み表示＋詳細ビューの IPA という文字提示のみ**。音声・TTS・発音判定は持たず、発音はメカニクスに一切関与しない（DP1/DP2）。音声はポストリリースの任意ストレッチ。
- オープンワールド：対象外（フロア制を堅持）。
- 古ノルド語の網羅的再現：対象外。学習設計上必要な範囲に限定する。
- 物語の大規模分岐：対象外。枠物語は `1.5` で確定した最小形（滅び／師匠／巻き戻し語＋記録アーティファクト／7日ループ／Helgrind 攻略）に固定し、分岐エンドや大規模サブクエストは作らない。物語はメカニクスの理由付けに徹する。

### 6.1 ローカライズ方針（DL1・確定）
- **日本語を主として先行開発、英語はリリース必須要件**（本ジャンル＝言語学×ローグライトの主要層が英語圏のため。後回しストレッチではなくリリースゲート）。
- 全 UI 文字列・学習グロスは **i18n テーブルとして外部化し、構造は INC-0 から用意**（後付け i18n は改修が重い）。コア検証期（INC-1〜4）は日本語のみ作成で可、英語の全文・全グロス完備は INC-5/6（`02`/`05`）。
- 古ノルド語の語そのものは翻訳対象外（学習対象）。翻訳されるのは UI とグロス（意味説明）。グロス言語は UI ロケールに従属。

## 7. リスクと対策

| リスク | 影響 | 対策 |
|--------|------|------|
| 呪文文法エンジンが面白くならない / 複雑すぎる | 致命的 | M1 で単独プロトタイプ検証。面白くなければ文法スコープを縮小する判断ゲートを設ける |
| 言語学習がストレスになり「勉強」化する | 高 | 失敗を罰でなく情報に変える設計（暴発＝原因が分かる）。死亡で蓄積を可視化 |
| 古ノルド語の言語的誤り | 中（信頼性） | M5 に言語監修フェーズを設置。`05` のスキーマに出典欄を必須化 |
| タイムリミットが理不尽に感じる | 中 | 失敗も理解度が残る設計で緩和。時間収支を UI で常時可視化 |
| 縦切り前に横展開してしまう | 中（進行） | `02` のマイルストーンでゲート管理。M2 完了まで content 追加禁止 |

## 8. 成功指標（プレイテスト時に測る）
- 新規プレイヤーが説明書なしで「最初の正しい呪文」を撃つまでの時間 < 5分。
- 3周時点で辞書参照頻度が初回比で減少している（暗記が起きている証拠）。
- 「死んでも前進している」とプレイヤーが言語化する割合 > 70%。
- 「理解度＝制御精度」をプレイヤーが自力で言語化できる。

> 上記は**面白さ／学習**の指標。**届く／売れる**の指標（ウィッシュリスト速度・フック反応・デモ離脱点）は別軸として `07_市場・リリース戦略.md` を正とする。設計が良いだけでは収益にならない（収益前提は `07` §0）。
