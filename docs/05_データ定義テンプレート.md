## 1. WordResource（語彙）

呪文エンジンの最重要データ。語形変化を**データで**保持する（コードにハードコードしない）。

```jsonc
{
  "id": "fjandi",                 // 一意キー（基本形）
  // 03 附録Aの語クラス分類に準拠（v0.9: suffix → direction に名称変更、03 v0.18 と整合）
  "word_class": "target",         // effect|target|element|modifier|range|direction|conditional|cond_detail|numeral|time_unit
                                  // 旧 "suffix" は v0.9 で "direction" に rename。既存データの 4 語 (fram/aptr/vinstri/hœgri) はマイグレーション対象
  // 学習用の意味（伏せ表示の対象）。ロケール別キー（DL1: JA先行・ENはリリース必須）
  "gloss": { "ja": "敵", "en": "enemy" },
  // 発音（表示補助のみ・非メカニクス。DP1/DP2）。カナは表示補助、正典トークンは古綴ラテン表記
  "reading_kana": "フィアンディ",   // カナ読み（旧辞典より。無辞書モードでは非表示＝DP3）
  "ipa": "ˈfjan.di",              // 詳細ビュー用・任意（旧辞典の検証IPAより。無くてもよい）
  "gender": "masculine",          // 名詞/形容詞のみ: masculine|feminine|neuter
  "tier": 1,                      // 1|2|3 固有威力ティア（理解度と独立。03附録Aの暫定tier）
  "comprehension_default": 0,     // 新規発見時の理解度（通常0）

  // 格変化表（対象語は必須。03 §3.3 の格運用ルール）
  "inflection": {
    "sg": { "nom": "fjandi", "acc": "fjanda", "dat": "fjanda", "gen": "fjanda" },
    "pl": { "nom": "fjandr",  "acc": "fjandr", "dat": "fjǫndum","gen": "fjanda" }
  },

  // 効果語のみ: 要求する目的語の格
  "governs_case": null,           // effect例: "acc"

  // 条件語/接続等のみ: 構文上の役割
  "function_role": null,          // "if" 等

  "discovery": ["inscription", "drop"],  // 入手手段タグ（旧辞典の習得地域は非流用）

  // 出典・信頼度（03 附録Aから転記。旧辞典の文献裏取りを活用）
  "source": "CV s.v. fjándi; Zoëga",     // 出典（必須）
  "confidence": "verified",       // verified(✅) | review(◎) | ambiguous(⚠) | unchecked(❓)
  "verified": true               // confidence=verified を満たすか（M5監修で確定）
}
```

> 語彙データの初期投入は **`03_呪文文法仕様書.md` 附録A の抽出台帳** を正とする。`source`/`confidence`/`verified` は附録Aの出典・信頼度（✅◎⚠❓）をそのまま転記する。✅→`verified:true` 候補、◎⚠❓→M5 監修対象（`verified:false` で投入）。

**バリデーション要件**
- `word_class=target` → `gender` と `inflection` 必須（格一致のため）。
- `word_class=effect` → `governs_case` 必須（自動詞/移動効果は `"none"`）。
- `word_class=conditional` → `function_role` 必須。
- `word_class=element` → 元素相性メタ（混沌参加可否）を `discovery` 等とは別に持つ（実装側で属性合成解決）。
- **`word_class=range`（v0.9）** → `spatial.kind` 必須（`distance` / `shape`）。`spatial.params` で射程/形状を定義（例: `{ "kind": "distance", "params": { "min": 1, "max": 2 } }`）。座標系上の意味は `09 §7.1` を正典とする。
- **`word_class=direction`（v0.9・旧 suffix）** → `spatial.kind: "direction"` 必須。`spatial.params` で相対方向を定義（例: `{ "kind": "direction", "params": { "axis": "forward" } }`、軸は `forward`/`backward`/`left`/`right`）。`09 §7.2` を正典とする。
- `confidence ∈ {verified, review, ambiguous, unchecked}`。`verified=true` は `confidence=verified` のときのみ許可。
- `tier ∈ {1,2,3}`、`comprehension_default ∈ [0,100]`。
- `gloss.ja` 必須。**`gloss.en` はリリース必須**（DL1: ジャンル主要層が英語圏のためリリースゲート。INC-0〜コア検証期は JA のみで可、EN は INC-5/6 で完備）。`reading_kana` 必須（表示補助）。`ipa` 任意。
- 発音系（`reading_kana`/`ipa`）は**表示・教育用のみで、パース/判定/威力に一切関与しない**（DP2）。正典トークンは古綴ラテン表記（`03` 表記ポリシー）。

> **【ローカライズ方針・確定（DL1）】**：UI文字列・グロスは全て**外部化（i18nテーブル）し INC-0 から構造を用意**する（後付け i18n は改修が重いため構造だけ先行）。日本語を主として先行作成、**英語はリリース必須要件**（後回しストレッチではない）。グロス言語は UI ロケールに従属（日本語UI→`gloss.ja`、英語UI→`gloss.en`）。コア検証期（INC-1〜4）は JA のみ作成で可、EN 全文・全グロスの完備は INC-5/6 のリリースゲート（`02`）。

> **【INC-0/1 必須・最小コア格変化】**（`03` §3.3 の矛盾解消と一致）：格一致はコア体験のため、以下の語の **主格・対格** が INC-0/1 時点で `inflection` に存在しなければならない（暫定値・`verified:false` 可、ただし存在必須）。全パラダイム（与格/属格）と精緻な語形確定・出典確定は INC-5（言語監修）に後置。
>
> 必須最小セット: `fjandi`(nom `fjandi`/acc `fjanda`)、`sjalfr`(nom `sjálfr`/acc `sjalfan`)、四大元素 `eldr`(nom/acc `eldr`/`eld`)・`vatn`(`vatn`/`vatn`)・`vindr`(`vindr`/`vind`)・`jorth`(`jörð`/`jörð`)。語形は暫定（旧辞典は格変化を意図的に省いていたため新規付与）。INC-5 で監修確定。

## 2. GrammarRuleset（構文の可用性集合）

`03` §6 確定モデルを実現。**`enabled` は「その構文が使用可能（導入済み）か」を表す＝可用性ゲート**。`enabled:false` は寛容に無視するのではなく、その構文・語を**プレイヤーに登場させない**。コア規則（格一致・語順）は常に `enabled:true` で**段階に依らず厳格判定**（寛容化しない＝D3 補助型）。Validator に注入する。

```jsonc
{
  "id": "phase_beginner",
  "label": "初級",
  "rules": {
    // コア規則: 常に true（厳格判定。寛容フェーズは存在しない）
    "case_agreement":   { "enabled": true,  "severity": "moderate", "core": true },
    "word_order":       { "enabled": true,  "severity": "minor",    "core": true },
    "word_order_bonus": { "enabled": true,  "weight": 0.15 },
    // 可用性ゲート: 解禁されるまで false＝当該構文/語を入力に出さない（寛容化ではない）
    "elements":         { "enabled": true,  "severity": "minor" },   // 初級+で属性語
    "modifier":         { "enabled": false, "severity": "minor" },
    "range":            { "enabled": false, "severity": "minor" },
    "number_agreement": { "enabled": false, "severity": "minor" },
    "condition_clause": { "enabled": false, "severity": "severe" },
    "negation_scope":   { "enabled": false, "severity": "severe" }
  },
  // 補助段階（03 §6.1）。UI層(SpellComposer)が解釈。Validatorの合否・Gには不関与。
  "scaffold_level": "mid",   // max | mid | low | none （無辞書モードは none＋最厳強制）
  // severity → 文法スコア G の減点幅・フィードバック強調度に寄与（03 §3.3/§5.4/§7）。
  // 注: v0.7で暴発確率は理解度のみ＝severityは暴発確率に不関与。文法は数値ステータスを持たない(D1)。
  "severity_weights": { "minor": 1.1, "moderate": 1.3, "severe": 1.8 }
}
```

フェーズ例: `phase_intro`(scaffold:max) / `phase_beginner`(mid) / `phase_intermediate`(low) / `phase_advanced`(none)
（`01` 4章・`03` §6 と一対一対応）。コア規則は全フェーズ共通で `core:true` かつ `enabled:true`。フェーズ差は (a) 可用性ゲートの解禁範囲、(b) `scaffold_level` のみ。

## 3. BalanceConfig（数式係数）

`03` §5 の**式は固定、係数はデータ**。M5 でここを調整する。

```jsonc
{
  "control": { "w_comprehension": 0.6, "w_grammar": 0.4 },
  "variance": {
    "v_max_by_tier": { "1": 0.10, "2": 0.25, "3": 0.45 },
    "j_max_by_tier": { "1": 0.10, "2": 0.30, "3": 0.55 }
  },
  "misfire": {
    // 確率（03 §5.2・確定）: p = clamp(0.10 - 0.001*C, 0, 0.10)  ※理解度のみ。文法/ティア/語順は確率に不関与
    "base_at_zero": 0.10,                 // 理解度0での暴発率（10%）
    "decay_per_comprehension": 0.001,     // 理解度1ごと0.1ポイント減（C=100で0＝暴発なし）
    "comprehension_input": "weighted_avg",// 正典: 使用内容語の加重平均（"min"=weakest-linkはINC-1で要否検証）

    // 重篤度バンド（03 §5.3）: 暴発時、Cで失敗の質が悪化（頻度は下がるが内容は悪化）
    "bands": {
      "low":  { "max_c": 30,  "category": "activation",  "outcomes": { "fizzle": 0.7, "collapse": 0.3 } },
      "mid":  { "min_c": 31, "max_c": 60, "category": "execution", "outcomes": { "target_shift": 0.45, "power_drop": 0.40, "halve_or_misrange": 0.15 } },
      "high": { "min_c": 61, "max_c": 99, "category": "control",   "outcomes": { "self_damage": 0.55, "effect_reversal": 0.30, "recoil": 0.15 } },
      "none": { "c": 100 }                // 暴発しない（0.10-0.001*100=0）
    },
    // 結果パラメータ（質の強さ。INC-1/5で調整）。被害量は語ティアに比例（03 §5.2）
    "params": {
      "power_drop_range": [0.30, 0.70],   // mid: 威力倍率の落ち幅
      "self_damage_ratio": 0.40,          // high: 意図威力のうち自分に返る割合
      "self_damage_tier_scale": true      // high: 被害は構成語ティア合計に比例（強呪文の自爆ほど痛い）
    }
  },
  "word_order_bonus": 0.15,

  // 暴発倍率テーブル（v0.9: 03 v0.11/v0.13/v0.14/v0.18 で導入された倍率を正式データ化、`03 §5.2`）
  // INC-1〜INC-3 では range_*/direction_* は実質適用なし（minor finding にとどめる）。INC-3.5 で有効化。
  // INC-3 暫定実装は `core/spell/resolver.gd` の `MISFIRE_MULT_BY_RULE` static var に直接書き、本表は宣言として参照。
  "misfire.mult_by_rule": {
    "case_agreement":      2.0,  // 格不一致 (03 §3.3 / v0.11)
    "unknown_word":        4.0,  // 綴り誤り＝辞書未マッチ（無辞書経路のみ、v0.11）
    "word_order":          6.0,  // 語順違反 (03 §3.2 / v0.11 / v0.15)
    "elements":            1.5,  // 半端な属性合成 (v0.13)
    "modifier":            1.5,  // 修飾語単独使用 (v0.13)
    "modifier_agreement":  2.0,  // 修飾語の性数格不一致 (v0.14)
    "range_required":      2.0,  // 射程外 (v0.18 / INC-3.5 で有効化)
    "range_conflict":      3.0,  // 範囲語相互矛盾 nær×fjarri 等 (v0.18 / INC-3.5)
    "direction_required":  2.0   // AoE / 貫通で方向未指定 (v0.18 / INC-3.5)
  },

  // AoE 倍率（v0.9 新規・暫定）: vítt の AoE 詠唱で複数敵にヒットした場合の総ダメ抑制
  // 1.0 = 単純合算（敵 N 体に effect_power × N の総ダメ）。INC-3.5 の C6 シナリオ実測で調整 (08 §6.3)
  "aoe.damage_split": 1.0,

  // ダンジョン・マップ（v0.9 新規、09 §2/§4）
  "dungeon": {
    "size": [40, 30],                 // 1 階のタイル寸法（INC-3 暫定。09 §11 calibration 対象）
    "rooms_per_floor": [5, 8],        // 1 階あたり部屋数のレンジ
    "room_size_range": [[5, 4], [10, 8]],  // [[min_w, min_h], [max_w, max_h]]
    "floors_total": 3                 // INC-3 暫定: 3 階で打ち止め。INC-5 で拡張
  },

  // 視界（v0.9 新規、09 §4.1）
  "fov": {
    "radius_player": 8,               // プレイヤーの視界半径（タイル）
    "radius_enemy":  4                // 敵の視界半径（プレイヤーより短く・先手取りやすい）
  },

  // 詠唱コスト（MP の代替＝連打抑制。01 3.5/3.8、04 §6）
  "cast_cost": {
    "turns_per_cast": 1,              // 1詠唱＝1プレイヤーターン（固定）
    "world_time_base": 1.0,           // 世界時間Δの基礎
    "world_time_per_word": 0.5,       // 語数比例分
    "world_time_per_tier": 0.5        // 構成語ティア合計比例分（強く複雑な呪文ほど夜が早まる）
  },
  // 集中学習など他の世界時間消費は別途（01 3.3/3.5）
  // v0.9: move / turn_in_place を追加（09 §4.2）
  "world_time_costs": {
    "move":           0.5,            // 1 タイル移動。v0.9 新規・09 §4.2 calibration 対象
    "turn_in_place":  0.0,            // 旋回（向き変更のみ）。v0.9 新規・戦闘中の自由旋回を許す
    "study_focus":    5.0,            // 集中学習
    "inscription":    1.0             // 碑文翻訳
  },

  // 7 日ループの世界時間予算（v0.9 新規・01 §3.5 / 09 §4.2）
  // 抽象単位 168 = 24 × 7 を意味するわけではなく、calibration 対象
  "loop_world_time_budget": 168
}
```

> `world_time` の単位・初期値は **INC-3 の実測 calibration で確定**（`02` INC-3）。式の形は固定、数値は仮置き。MP は導入しない。
> 暴発の確率式（**理解度のみ・基準10%・−0.1pt/理解度・C=100で0**）と重篤度バンド境界（≤30 / 31–60 / 61–99 / =100）は**確定仕様**（`03` §5.2/5.3）。文法・語ティア・語順は v0.6 までは暴発確率に不関与だったが、v0.11 以降 `mult_by_rule` で合算される（`03` §5.2 経緯）。`bands.outcomes` の重みと `params` の強さは INC-1/INC-5 で調整する tunable。`variance`/`v_max`/`j_max` は「成功時の軽微なゆらぎ」用で、categorical な失敗は `misfire` が担うため控えめに保つ（二重ペナルティ回避、`03` §5.4）。
> **v0.9 注**: `dungeon`/`fov`/`world_time_costs.move`/`misfire.mult_by_rule.range_*` 等は INC-3 暫定値であり、INC-3 実機検証中の calibration 対象（`09 §11`）。INC-3.5 で `range_required`/`range_conflict`/`direction_required` を有効化し、INC-1/2 H/H2 再判定（`06 §6` / `08 §6`）で適切値を確定する。

## 4. EnemyResource（敵）

## 7. SaveData（永続・Lexicon のみ＝記録アーティファクトの刻印）

物語上は「時を記録するアーティファクト」の刻印（`01` 1.5、`04` §7）。巻き戻しても残るのはこれだけ＝主人公の記憶。

```jsonc
{
  "version": 1,
  "lexicon": {
    "lakna":  { "comprehension": 62 },
    "sjalfr": { "comprehension": 80 }
  },
  // 文法習熟（D1: 数値なし。解禁状態のみ。D7: 巻き戻しで戻らない＝知識側で恒久）
  "grammar_progress": {
    "unlocked_phase": "phase_intermediate",   // 到達フェーズ（可用性＋既定scaffold）
    "scaffold_level": "low",                   // プレイヤーが選んだ補助段階（解禁上限内で下げ可）
    "unlocked_constructs": ["effect_target","case","elements","modifier","range"],
    "unlock_reason": "story"                    // story（主）| mastery（従。前帯規則の正詠唱実績で前倒し）
  },
  "stats": { "loops": 7, "rewinds": 5, "words_discovered": 41, "helgrind_cleared": false }
}
```

> `04` §7 の不変条件: SaveData に HP/到達階/装備等のループ一時状態を**含めない**（巻き戻る側）。`grammar_progress` は知識側＝**巻き戻しで戻らない**（D7）。解禁の引き金イベントがループ内で起きても、解禁自体は恒久記録（語彙理解度と同じ扱い）。`scaffold_level` は到達フェーズの既定値以下へプレイヤーが任意に下げられる（手応えを上げたい上級者向け／無辞書モードは `none`＋最厳強制）。`stats.loops`/`rewinds`/`helgrind_cleared` は前述どおり。

## 8. 監修運用ルール（M5）

1. `verified=false` の語/碑文を一覧化し、言語監修者がレビュー。
2. 出典を `source` に明記（文献名・章節）。創作部分は「創作」と明示。
3. 語形修正は `WordResource.inflection` の差し替えのみで完結する設計（コード変更不要であること）。
4. 監修完了で `verified=true`。リリースは主要語が `verified=true` であることを条件とする。

## 9. TileKind（タイル属性、v0.9 新規）

マス目グリッド上の各タイルの種別を定義。`09 §3.3` を正典とする。データ配置: `data/tiles/tile_kinds.tres`。

```jsonc
{
  "id": "wall",                   // floor|wall|door|stairs_down|inscription|study_spot|player_start
  "passable": false,              // プレイヤー/敵が踏めるか
  "blocks_sight": true,           // FOV を遮るか
  "blocks_spell_path": true,      // 通常の詠唱パスを遮るか（`í gegnum` のみ貫通可、09 §7.1）
  "role": "wall",                 // 表示・ロジック上の分類（描画タイルとリンク）
  "interactable": false,          // プレイヤーがインタラクト可能か（碑文/学習スポットは true）
  "source": "オリジナル",
  "verified": true
}
```

**INC-3 最小実装で必須なタイル種別**: `floor` / `wall` / `stairs_down` / `player_start`（`09 §3.3`）。`door` / `inscription` / `study_spot` は INC-4 で要件化する後置項目。

**バリデーション要件**
- `id` は `09 §3.3` の正典リストにある値のみ許可。
- `stairs_down` は `passable: true` 必須。
- `wall` は `passable: false` ＋ `blocks_sight: true` 必須。
- `blocks_spell_path: true` でも `í gegnum`（貫通）は座標系上で貫通可（`SpatialResolver` の責務、`09 §7.1`）。

## 10. MapData / DungeonSeed（マップ実体、v0.9 新規）

`DungeonGenerator` が `FloorTemplate` から生成するランタイム実体。`09 §2` `§3` を正典とする。Lexicon に保存しない（ループ一時状態、`04 v0.6 §7`）。

```jsonc
{
  // DungeonSeed: 巻き戻しごとに新規生成
  "seed": 42,
  "loop_index": 3,                // 今までのループ累計（stats.loops と一致）
  "floor_depth": 1,

  // MapData: 1 階分のタイル配列と部屋情報
  "tiles": [                      // tile_size = [40, 30] なら 30 行 × 40 列
    ["wall", "wall", "wall", ...],
    ["wall", "floor", "floor", ...],
    ...
  ],
  "rooms": [
    { "x": 5, "y": 4, "w": 7, "h": 5, "kind": "start" },     // 起点部屋（fixed_start_room: true ならループ間で固定）
    { "x": 20, "y": 12, "w": 6, "h": 4, "kind": "normal" },
    { "x": 30, "y": 22, "w": 8, "h": 6, "kind": "stairs" }   // 階段部屋
  ],
  "corridors": [                  // 部屋間の通路リスト（L 字 or 直線、09 §2.1）
    { "from_room": 0, "to_room": 1, "path": [[12, 6], [15, 6], [15, 14]] },
    { "from_room": 1, "to_room": 2, "path": [...] }
  ],
  "stairs_down_pos": [33, 24],    // 階段タイルの絶対座標
  "player_start_pos": [8, 6],     // プレイヤー初期位置
  "enemies": [                    // 配置時の状態（巡回ターゲット込み）
    { "id": "draugr_lesser", "pos": [22, 13], "patrol_target": [24, 14], "hp": 18 },
    ...
  ]
}
```

> **巻き戻し時**: `MapState.reset()` → 新規 `DungeonSeed` 取得 → `DungeonGenerator.generate()` で `MapData` 再生成（`04 v0.6 §7`）。起点部屋は `seed_policy.fixed_start_room = true` のときループ間で同じ座標・寸法で生成（精神的アンカー、`09 §2.5`）。
>
> **MapData は保存しない**: SaveData (`§7`) には含めない。ループ一時状態として `MapState` autoload (`04 v0.6 §3`) のみが保持し、`reset()` で破棄。語彙知識との明確な分離（テーマ「知識は残るが世界は戻る」の実装側の保証点）。
