## 0. 共通ルール

- **公開はすべて人間承認後**（`sns_posting_policy.md` §3）。エージェントは `{{プレースホルダ}}` を埋めて提示するところまで。
- 4 本柱の比率目安 **4 : 3 : 2 : 1** を月単位で意識する（柱1フック / 柱2 devlog / 柱3 小ネタ / 柱4 節目）。
- 画像・GIF は **実ビルドのみ**。素材が無い段階のテンプレには使わない。
- ハッシュタグは **1 投稿あたり 3 個まで**。
- CTA は基本「ウィッシュリスト（Steam）」。Steam ページが無い段階では CTA を入れず、devlog の発見回路としてのみ機能させる。

## 2. devlog 定型（週 1〜2、4本柱の "柱2"）

### 2-A 進捗報告（実装トピック）

```
devlog #{{番号}} — {{何を実装したか・1行}}

{{2〜3行の補足。何が難しかったか／何が動いたか。失敗があれば書く（真正性資産）}}

{{GIF または静止画。実ビルドのみ}}

#Godot #indiedev #gamedev
```

### 2-B 進捗報告（言語実装トピック）

```
devlog #{{番号}} — {{古ノルド語/文法エンジン関連の進捗・1行}}

{{古ノルド語の挙動を1〜2行で。例: "格変化を入力すると詠唱の効果範囲が絞り込まれるようにした"}}

{{GIF。テキスト入力→効果変化が見える 8〜15 秒推奨}}

#OldNorse #indiedev #Godot
```

### 注意

- 番号 `#NN` は通し番号。エージェントが連番を管理。
- "達成感だけ" の投稿は連続させない。**実装の手触り**を1つ入れる（数字でなく感覚）。

## 3. スクショ／GIF 単発告知（柱1 フック）

「フック動画/GIF は単独で完結すること」が原則。テキストは最小限。

### 3-A 単発フック

```

```

または日本語側:

```
{{1行のフック。例: "与格を読めると、この呪文の制御精度が上がる。"}}

```

### 注意

- 説明を盛らない。**1 投稿 = 1 フック**。
- 字幕は最小限・**言語非依存に寄せる**（拡散の天井を上げるため）。
- ルーン字形が崩れていないかモバイル実機で必ず確認。

## 7. 使ってはいけない表現パターン

エージェントは下書き段階でも以下を**生成しない**。

- 「世界を変える」「ゲームを変える」「革命的」「史上初」「待望の」
- 競合作品名を出して比較する表現（"〇〇 を超える"、"〇〇 系の決定版" 等）
- 数値の感覚的盛り（"何百時間も遊べる"、"圧倒的なボリューム"）— 未測定／未確定
- フォロワー数・いいね数に言及するメタ投稿（虚栄指標を強化する）
- AI が書いたことを誇示する投稿、または隠して "私が深夜に書きました" 的に偽装する投稿
